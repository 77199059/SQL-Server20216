# Conceptos SQL
Este repositorio contiene documentos y ejemplos básicos sobre SQL.

## Contenido
- SQLBasico.docx → Documento con conceptos básicos.
- SQLBasico_Explicado.md → Explicación detallada en formato Markdown.
- Carpeta `imagenes/` → Recursos gráficos de apoyo.

## Objetivo
Ayudar a estudiantes a comprender los fundamentos de SQL de manera práctica.
